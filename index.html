NAVEGA360 · PUBLICAR EN GITHUB

Exportar recorrido optimizado

GitHub admite archivos de hasta 25 MiB desde su sitio web. El editor puede reducir el peso de las fotografías solo en el ZIP exportado; tus originales y hotspots permanecen sin cambios.

Las panorámicas mantienen la proporción 2:1, la orientación y la posición de todos los hotspots. Las imágenes pequeñas pueden conservar su formato original. Las fotografías PNG muy grandes podrían convertirse a JPG, sin transparencia.

Recuerda: descomprime el ZIP y sube los archivos y la carpeta assets/ a GitHub. No subas el ZIP completo.

PUBLICAR EN INTERNET

Enlace de recorrido en modo visitante

El botón ☁ Publicar enlace permite enviar fotografías y música a Vercel Blob y compartir un enlace que solo permite visualizar el recorrido.

  1. Guarda el código del editor en GitHub y conéctalo con Vercel.
  2. En Vercel → Storage crea y conecta un almacenamiento Blob público al mismo proyecto.
  3. En Settings → Environment Variables configura NAVEGA_ADMIN_PASSWORD y vuelve a desplegar el proyecto.
  4. Desde ☁ Publicar enlace, escribe la contraseña y pulsa 🔎 Comprobar conexión con Blob para confirmar la configuración.
  5. Cuando la comprobación sea correcta, pulsa ☁ Guardar y actualizar recorrido en línea y copia el enlace del visitante.

La edición se guarda en este navegador. Conserva tus archivos originales. La exportación ZIP sigue disponible como respaldo alternativo.
